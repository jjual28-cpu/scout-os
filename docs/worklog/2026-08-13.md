### 2) 회원가입 버그 수정
- 이미 가입된 이메일 재가입 시 "메일 발송"으로 오인되던 것 → **"이미 가입된 이메일" 안내**. Supabase 열거방지의 빈 `identities` 감지. `features/auth/hooks/use-auth.ts`.
- ⚠️ 별개: **새 이메일 가입 확인메일이 안 오면** Supabase SMTP(Resend) 설정 확인 필요(미해결, 필요 시 점검).

### 3) 인스타그램 웹훅 구독 (답장 자동수신 활성화)
- OAuth 후 `subscribeMessagingWebhook()` — `POST /{ig}/subscribed_apps?subscribed_fields=messages`. 이게 없으면 연동해도 답장이 안 들어옴.
- 콜백에서 자동 호출 + 복구용 `POST /api/instagram/subscribe` + 설정 카드 "답장 수신 재연결" 버튼.
- `.env.example`에 인스타 4개 키 문서화.
- ※ 집 작업(App Review 콜백 disconnect/data-deletion/deauthorize)과 합쳐져 **인스타 코드는 심사 대응까지 완비.** 남은 건 Meta 앱 설정(별도 트랙).

### 4) 검색 속도 개선 Phase A (효과 미미)
- `MIN_SUFFICIENT 12→10`(조기종료), `POSTS_LIMIT 50→30`, `stage1 24→16`, `stage3Cap 상한 40→24→16`, status `TARGET 30→20`.
- **결과: 여전히 ~4분.** Apify 데이터로 원인 확정 → **아래 "속도" 참고.**

### 5) AI 무료화 — Google AI Studio(Gemini) 지원 ⭐ (오늘의 핵심)

- 키 없으면 기존 OpenRouter 그대로(무변경, 안전).

## ⚠️ 오늘 밝혀진 결정적 사실 2개

### A. AI 판정이 지금까지 한 번도 안 돌고 있었음
- 검색 결과에 뜨는 노란 경고 **"AI가 아직 설정되지 않아 자동 판정을 건너뛰었어요"** = **`OPENROUTER_API_KEY`가 Vercel에 없음** (운영·프리뷰 둘 다).
- 즉 "AI가 맞는 셀럽 찾아줌" 핵심이 규칙 필터로만 돌던 것 → 업체 섞이고 랭킹이 가짜였음.
- OpenRouter 잔액 `-$0.07`(마이너스)이고 결제창(Add Credits)이 브라우저에서 안 열려(시크릿에서도) 충전 실패.
- **해결책: Google AI Studio 무료 키**(카드 불필요) — 코드 지원 추가·배포 완료. **사용자가 키만 넣으면 켜짐.**

### B. 검색 속도 병목 = Apify 액터 자체 (Apify Runs 데이터로 확정)
- `apify/instagram-scraper`가 **프로필 상세 24개 스크랩 = ~3.5분** (프로필당 ~9초, 최근 게시물까지 브라우저 렌더).
- 흔한 검색도 stage1 한 번이 ~3.5분이라 **병렬화·개수축소로는 sub-1분 불가.**
- `resultsLimit`(프로필당 게시물 수) 3으로 줄이는 실험(`perf/search-fast-detail`) → **효과 없음(여전히 4분).**
- **진짜 해결 = 액터 교체**: `apify/instagram-profile-scraper`(내부 API, 프로필당 ~1~2초, 게시물도 반환해 참여율 유지). 조사 완료, 미구현.
